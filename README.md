# 网络监控（netmon）· 内置下行带宽消耗器

![GitHub release](https://img.shields.io/github/v/release/apangpeng/fnnet-monitor?color=blue&label=Release)
![GitHub stars](https://img.shields.io/github/stars/apangpeng/fnnet-monitor?color=green&label=Stars)
![GitHub last commit](https://img.shields.io/github/last-commit/apangpeng/fnnet-monitor?color=orange&label=最近更新)

飞牛 fnOS 网络监控面板，专为 PCDN 业务场景优化，并内置「下行带宽消耗器」（PCDN 业务版块）。

> 默认端口 **8778**。支持电脑 / 手机浏览器访问。

## 功能

### 网络监控（主界面）
- **网卡总览**：每张物理/虚拟网卡的下载/上传实时速度、累计流量、丢包/错误、MTU、速率、驱动、MAC、IPv4/IPv6 地址（卡片式展示，固定排序不跳动）
- **PCDN 业务总览**：上行带宽占用率大数字、每月上行流量配额进度条、业务流量排行（虚拟机 / 容器 / 网卡）
- **协议整体统计**：TCP / UDP / ICMP / ICMPv6 全局计数，含重传率、连接状态分布
- **正在监听的端口**：按用途分组（文件共享 / 飞牛系统 / 远程与虚拟机 / 应用服务 / 本应用），每张卡带中文说明；端口表外的动态端口按**进程名兜底**自动识别（qBittorrent、迅雷网盘、Docker 容器映射等）
- **Docker 容器流量**：每容器累计 NetIO + 实时速率
- **历史曲线**：网速历史曲线（物理网卡合计）+ 网卡详细计数表
- 自动识别飞牛虚拟机（vnet/veth/tap 网卡）并在显示层修正上下行方向

### 下行带宽消耗器（PCDN 业务版块）
- 按设定限速持续消耗下行流量，**固定为不落盘**（数据直接丢弃、仅统计流量，不写盘不磨损硬盘）
- **下行限速填 0 = 不限速**；**每日消耗目标填 0 = 不限流量**
- 下载源自动轮换：内置测速文件源 + 开源镜像源池，未手动编辑时每次下载自动按日期随机挑选（2 个测速文件 + 2 个镜像，每天不同），避免长期盯同一镜像站被限速
- 访问口令保护（X-Auth-Token），数据存于应用数据目录 `dc/` 子目录
- 配置入口：网页右上角「⚙ 设置」配置套餐带宽 / 月配额

## 安装

1. 下载最新版 fpk：**[Releases 页面](https://github.com/apangpeng/fnnet-monitor/releases)**（推荐）或仓库内 `网络监控-<版本>-内置下行带宽消耗器.fpk`
2. 飞牛 fnOS 应用中心 → 手动安装 → 选择该 fpk
3. 打开应用，访问 `http://<NAS-IP>:8778`


## 自行打包

```bash
# 修改 fpk_build.py 中的 OUT 文件名后
python fpk_build.py
```

## 使用提示

- 下行带宽消耗器用于按需消耗宽带下行额度，**请确认用途合法**，并留意运营商对持续大流量的限速与套餐条款
- 默认下载源均为公开合法大文件（OVH/Hetzner/Tele2 测速文件、Ubuntu/Debian/Arch/openSUSE 开源镜像）
